BLUP — исправление списка банков и виджета суммы продаж

Изменения:
- Банк получателя отображается вертикальным списком: одна широкая строка на банк.
- Убрано сжатие названий до вертикальных букв на узких экранах.
- Нормализуются списки банков из настроек, включая разделители \n, обратный слеш, ; и |.
- Иконки банков используют локальные SVG из public/assets/banks.
- API /api/reviews/total считает все записи отзывов через чтение всех sale_amount.
- Виджет суммы продаж обновляется раз в 30 секунд; при временной ошибке основного API пробует резервный /api/reviews и не показывает пустой прочерк.
- Существующие данные, отзывы, аккаунты, курс валют и анимированная иллюстрация сохранены.

Перед развёртыванием:
- Не удаляйте постоянный каталог /data и файл базы данных.
- Сохраните текущие переменные окружения.
- Перезапустите приложение после замены файлов.
