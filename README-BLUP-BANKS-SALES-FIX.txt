BLUP — исправление банков, селектов админки и суммы продаж

Исправлено:
- Выбор банка на форме продажи снова работает как компактная кнопка с раскрывающейся панелью списка, а не как постоянно открытый список карточек. Выбранный банк сохраняется в поле заявки.
- В админке раскрывающиеся поля «Награда» и «Скидка» снова показывают меню: общий styles.css скрывал меню через display:none, поэтому добавлен явный display:block для открытого состояния.
- Виджет «Сумма продаж» теперь инициализируется после разбора HTML. Ранее app.js запускался раньше, чем браузер успевал создать виджет в конце index.html, из-за чего скрипт завершался без запуска обновления. Добавлен defer и новый параметр версии для обхода кеша.
- Сумма всех отзывов считается агрегатным SQL-запросом по всей таблице, а не по ограниченному списку последних 50 отзывов.

Развёртывание:
- Заменить файлы проекта из архива.
- Не удалять /data и базу данных.
- Сохранить текущие переменные окружения.
- Перезапустить приложение.
