# BLUP — обновление каталога CS2

## Что обновлено
- При запуске сервер автоматически обновляет каталог CS2 в фоне; далее повторяет синхронизацию каждые 12 часов.
- Метаданные загружаются из ByMykel CSGO-API: оружейные скины с вариантами износа, StatTrak/Souvenir, кейсы и капсулы, наклейки, граффити, агенты, нашивки, брелоки, музыкальные наборы, ключи и другие доступные категории.
- Рыночные цены берутся из публичных USD-списков Skinport и Market.CSGO. Для одного предмета используется самая низкая доступная цена из этих источников.
- В основной каталог попадают предметы с ценой от $0.05 до $55.00 включительно. Предметы без найденной рыночной цены не выдаются за актуально оценённые.
- При недоступности рынков сайт продолжает работать с последним локальным каталогом.
- Все 25 кейсов BLUP, их содержимое, названия, изображения и цены сохранены без пересчёта. Существующие ID предметов, используемые этими кейсами, сохраняются.
- Каталог апгрейдера также использует диапазон $0.05–$55.00.

## Источники
- ByMykel CSGO-API — метаданные предметов и изображения: https://github.com/ByMykel/CSGO-API
- Skinport public items API: https://api.skinport.com/v1/items?app_id=730&currency=USD
- Market.CSGO public USD price list: https://market.csgo.com/api/v2/prices/USD.json

Цены — это снимок минимальных доступных листингов на момент синхронизации, а не гарантированная цена продажи или цена вывода. Список зависит от наличия предмета на выбранных рынках. API и рынки могут менять формат или ограничивать запросы.

## Ручной запуск синхронизации
Из корня проекта:
```bash
npm run sync:cs2
```

Скрипт обновляет `cases-data.json` и `public/cases-data.json`. Если оба источника цен недоступны, он завершится с ошибкой и не заменит рабочий каталог.

## Розыгрыши
В этой версии сохранена существующая система розыгрышей:
- запуск из `/admin`;
- бесплатное участие при минимуме продаж `$0`, либо серверная проверка завершённых продаж на заданную сумму;
- максимум 5 мест и 5 PNG-призов;
- список участников с ником и ID сайта;
- завершение розыгрыша администратором с фиксацией победителей;
- запуск нового розыгрыша очищает предыдущий розыгрыш, его PNG и список участников.
