BLUP GTA VI REDESIGN V2
=======================
Обновлено:
- Общая финальная палитра GTA VI / Vice City: графит, розовый, фиолетовый и неоновый голубой. Новый слой подключён после старых таблиц стилей на всех HTML-страницах.
- Розовый шар BLUP добавлен в favicon всех страниц.
- Главная: удалена полоса с максимальной суммой сделки и постоянными курсами; вместо неё справа плавающая кнопка «Курс валют» с раскрывающейся панелью, значения берутся из /api/config.
- «Розыгрыши» на главной открывает модалку; текущий розыгрыш и кнопка участия загружаются из существующих API. Участники в колесе визуально анонимны (без ников и ID).
- Cases: старый GIF-агент заменён на иллюстрацию GTA/Vice City из каталога кейсов с мягкой CSS-анимацией.
- Admin: основные карточки можно сворачивать; добавлена очистка истории входов через существующий защищённый DELETE /api/admin/visits.
- Сохранены существующие серверные маршруты и данные.
ВАЖНО:
- Автоматический запуск серверного выбора победителя по времени МСК не включён: для этого нужна миграция БД с полем дедлайна и серверный планировщик, а текущая форма и таблица розыгрыша не хранят дату окончания. Существующая кнопка/маршрут ручного завершения остаётся рабочей. Не выдавать фронтендовый таймер за надёжное автоматическое завершение.
- Колесо пока декоративно показывает анонимные сектора, не имитирует подтверждённый результат. Сам выбор победителей остаётся на сервере через существующий защищённый маршрут завершения.
- Проверить на staging после развёртывания: модалку, курсы, админ-очистку истории, картинки кейсов, мобильную вёрстку.
