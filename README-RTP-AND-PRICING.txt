BLUP: экономика кейсов, апгрейды и производительность

- Все 25 кейсов сохранены. Их цены рассчитаны из матожидания выпадений при целевом RTP 90%: EV = сумма (цена предмета × вероятность), цена кейса = EV / 0.90.
- Для каждого кейса записаны явные вероятности c.chances; сумма шансов равна 100%. Клиентские подсказки и серверный RNG используют эту же таблицу.
- Текущие цены кейсов находятся примерно в диапазоне 148–249 RUB при курсе 82.829 RUB/USDT, то есть внутри заданных границ 78–1500 RUB. Не все кейсы доходят до 1500 RUB, потому что текущий каталог слишком мал и не содержит достаточно дорогих предметов для экономического обоснования такой цены.
- Внутренняя цена и баланс остаются в USDT; отображение RUB использует курс /api/cases/config. Цена открытия списывается в USDT.
- RTP на карточках и странице кейса рассчитывается по вероятностям и стоимости содержимого, не является декоративным значением.
- Апгрейд серверно ограничен диапазоном 1–86%. Слова о редкости убраны из карточек апгрейда; цветовая группировка и сортировка по качеству сохранены.
- Открытие кейсов принимает предметы каталога в диапазоне $0.05–$55.00.
- Убрана повторная загрузка полного внешнего каталога скинов браузером на каждой странице. Изображения берутся из серверного кэша и каталога.
- ВАЖНО: синхронизация маркет-цен в этой среде не удалась (fetch failed). В текущем JSON по-прежнему 34 предмета. Для полного каталога и свежих цен запусти `npm run sync:cs2` в окружении Amvera с доступом к интернету. Скрипт не должен заменять локальные данные, если источники недоступны.
