BLUP — исправление апгрейда и отображения валюты

1. Восстановлено сохранение выбранной цели при выборе/снятии исходных скинов.
2. Смена множителя и суммы баланса больше не сбрасывает целевой скин.
3. Кнопка «УЛУЧШИТЬ» активируется после выбора ставки и целевого предмета дороже ставки.
4. На страницах кейсов, инвентаря и апгрейда используется общая настройка валюты blupDisplayCurrency.
5. В режиме долларов цены показываются со знаком $, в режиме рублей — со знаком ₽.
6. Курс RUB/USD для отображения берётся из /api/cases/config (админская настройка курса).

Проверка:
- Синтаксис изменённых JavaScript-файлов проверяется перед публикацией.
- Для проверки фактической работы API требуется запуск на сервере с базой данных и авторизацией.
