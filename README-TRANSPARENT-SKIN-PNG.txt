BLUP — прозрачные PNG-изображения скинов CS2

Что сделано:
- В интерфейсах кейсов, открытия и апгрейда изображения скинов отображаются как PNG-вырезки с прозрачностью.
- CSS больше не добавляет собственный фон, рамку или скруглённую подложку непосредственно на изображение.
- Серверный кэш сохраняет файл только если это настоящий PNG с альфа-каналом или прозрачностью tRNS.
- Источник ByMykel CS2 API отдаёт panorama-рендеры вида *_light_png.png; это прозрачные игровые изображения, а не фотографии с фоном.
- Если CDN недоступен, картинка останется недоступной до восстановления доступа к источнику; сервер не будет подменять её JPEG/WebP, названным .png.

После загрузки ZIP на Amvera сервер заполнит public/assets/skins при успешном обращении к каталогу CS2.
