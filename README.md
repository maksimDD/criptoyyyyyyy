# BLUP

Крипто-обменник с продажей USDT и GRAM, выводом с сайтов и Telegram-уведомлениями.

## Запуск на компьютере
1. Установите Node.js 20 или новее.
2. Выполните `npm install`.
3. Запустите `npm start`.
4. Откройте `http://localhost:3000`.

## Переменные окружения (для хостинга)
- `ADMIN_PASSWORD` — пароль администратора (по умолчанию `fosfor322322`).
- `SESSION_SECRET` — секретная строка для сессий.
- `TOKEN` — токен Telegram-бота для продаж.
- `REGISTER_BOT_TOKEN` — токен Telegram-бота для регистраций.
- `ADMIN_CHAT_ID` — ID чата для уведомлений.

## Страницы
- `/` — главная.
- `/admin` — админ-панель.
- `/maintenance` — страница технических работ.
