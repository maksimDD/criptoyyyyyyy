# BLUP

## Запуск
1. Установите Node.js 20 или новее.
2. Выполните `npm install`.
3. Задайте переменные окружения перед запуском:
   - `ADMIN_PASSWORD` — новый пароль администратора.
   - `SESSION_SECRET` — длинная случайная строка для сессий.
   - `SALES_BOT_TOKEN` — токен Telegram-бота для уведомлений (необязательно).
   - `REGISTER_BOT_TOKEN` — токен бота уведомлений о регистрации (необязательно).
   - `ADMIN_CHAT_ID` — ID чата для уведомлений (необязательно).
4. Запустите `npm start`.

Страница технических работ: `/maintenance`. Администратор может открыть её из панели управления.

Важно: старые токены Telegram, которые ранее были прописаны в исходниках, следует отозвать в BotFather и заменить. Не используйте реальные банковские данные в тестовой среде. Уведомления больше не пересылают пароли, номера карт/телефонов, банковские данные или адреса кошельков.


Административная панель: `/admin` (требуется `ADMIN_PASSWORD`). В ней можно управлять режимом технических работ и смотреть краткую историю заявок.
